# 05 · 在课表上完成排课和名单操作

前置04、06、07；原周/列表和写操作已实现，本轮双池与标签待调整；原验证记录见[docs/VERIFICATION.md](../docs/VERIFICATION.md)。实现于Timetable.tsx、Roster.tsx和SessionEditor.tsx；选人/换课保留为课次内组件。

Admin默认所有班级；周日历和列表同一API，关键词搜索班级/科目/老师，日期与班级/科目/老师过滤。筛选保存在URL可从学生详情带studentId进入，学生上下文不改变Admin全局课表权限。班级名优先，课次显示时间、科目、老师、人数/容量和试听人数，无开发说明条。

点击课次抽屉：基本安排、有效学生名单、新增/移除/换课、替课/改时间、修改记录；新增学生只从本人学生选，支持TRIAL/REGULAR。选中本人学生显示两个池可用量，会员可选TRIAL；试听池不足不能用正式余额顶替，REGULAR不足提供权益管理购课入口，缺联系人则指向学生档案。提交时仍由服务端重验，不凭页面余额放行。恢复取消预约独立入口，不能和首次添加混为无状态upsert。

调课确认展示受影响学生、原/新老师时间和原因，提交携带所确认参与者集合；409重新加载影响范围，保留原因和输入。换课列出同科目未来候选、时间、老师、人数/容量，确认后成功才改变界面，不乐观提前移走旧课。错误原地展示。

名单TRIAL置顶并可显示新会员/会员辅助标签，非试听按首次购课当地日起7日内NEW、再EXISTING；英文Trial/New member/Member。按本课当地日期判断，历史反馈读快照；不用原firstEnrolledOn/isNewToClass。学生Tab类型与本次参与kind不能混为一个字段。Teacher看同一组件的只读本人课次，不出现排课编辑或联系方式。反馈入口指向06任务表单。

修改记录位于课次详情，无独立系统审计管理页，显示操作者、时间、动作、原因和前后值；查看不等于已通知家长。

验收：Admin搜索找到跨班级课程并加学生，切列表仍是同一数据；Teacher任何筛选不能见别人课次；满员失败保留表单；换课后两边人数正确；会员仍能使用剩余试听、REGULAR余额不足明确阻止、试听/新会员/会员标签按该课日期稳定；空/加载/错误和窄屏正常。
