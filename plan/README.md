# 开发计划 · 试听闭环与学生权益

以[DESIGN](../DESIGN.md)、[共同约定](00-contracts.md)和[IMPLEMENTATION](../IMPLEMENTATION.md)为当前业务基准。原试听切片已实现，证据见[旧版验收](../docs/VERIFICATION.md)；**本轮三Tab、会员定义、双课时池和权益管理仅更新规格，尚未开发或验收。** [历史扩展方案](../docs/archive/expanded-design-v1/README.md)不作为执行清单。

## 本轮范围

- 学生管理一个页面三个互斥Tab：试听学生（从未购课）、新会员（首次购课当地日期起7日内）、会员学生（满7日）。续购不重置日期，正式余额为0仍是会员。
- 新增学生可输入初始试听课时，正整数默认1、最低1；余额用完可以0。会员身份与TRIAL参与方式独立，直接购课保留原试听权益。
- 独立权益管理，仅Admin管理本人学生；选择学生、手输正整数购买课时、备注。首次成功登记产生会员身份。课时套餐/优惠定价、支付退款不在本期。
- 每学生两个跨科目通用池，预约占用、到课扣1、取消/未到释放。替换“每生每科目一次试听”和“正式课无需余额”的旧规则。
- 沟通结果不能直接授予会员；购课流水驱动首次购课待办关闭，会员试听只产生回访，取消/未到重约任务保留。
- 家长仍内嵌Student；课表仍是ClassSession视图；不增加通用CRM/财务/菜单管理。

## 页面

| 入口 | Admin | Teacher |
| --- | --- | --- |
| 我的待办 | 本人首次购课跟进、会员试听回访、取消/未到重约 | 本人已结束待反馈课次 |
| 课表 | 全班日历/列表、筛选、加学生/换课/换老师、记录 | 本人课次与名单，试听优先、会员辅助标签 |
| 学生 | 三Tab、建档、本人联系方式和沟通；初始试听课时 | 三Tab只筛本人教学范围，无销售/权益详情 |
| 权益管理 | 本人学生双池余额、占用、可用、购课发放和流水 | 无入口，API同样拒绝 |
