# 01 · 简洁登录与管理布局

优先级 P0；状态：基础已实现。本任务后续只接入已完成页面，不实现各管理模块。

## 范围 / 文件

apps/web/src/pages/Login.tsx、components/Layout.tsx、App.tsx、auth.tsx。登录只保留品牌小标题、Account（仍为工作邮箱）、Password、Sign in，错误按需显示，不出现宣传文案或演示账号。桌面232px左菜单、右侧标题及主内容；窄屏菜单抽屉，不把长菜单挤在内容顶部。

## 规则

Admin 首页工作台；Teacher 首页 /timetable，仅两个入口 My lessons、My students。目标完整导航见 README。新增资源页和系统页时必须使用 AdminRoute，直接输入地址也拒绝；当前没有这些路由时不新增占位成功页。未登录跳登录，401清会话；logout仍服务端撤销。

账号密码错误保留账号，按钮请求中禁用。导航标记 aria-current；抽屉选中后关闭、键盘可用；面包屑来自路由注册表。菜单管理完成后接入23，之前固定已实现菜单。

## 验收

浏览器确认登录只含两个输入和按钮；正确登录进入对应首页；错误密码提示；Teacher 不见机构概览；退出后后退不能恢复私密数据。桌面与窄屏均能进入课表和学生页。本次代码已落实基本布局，动态菜单和未上线模块不在完成声明内。

## 界面表达约定（本轮调整）

页面以标题、筛选、数据和操作为主；不展示宣传语、开发进度说明、固定教学提示或重复时区胶囊。错误在出错位置显示，成功操作用短暂反馈。Admin课表默认All classes，班级筛选优先，提供Week/List视图；班级名优先于科目展示。桌面不重复堆叠顶栏标题和页面标题，移动端保留菜单按钮。
