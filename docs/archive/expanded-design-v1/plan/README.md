# 开发计划与执行入口

本目录将讨论拆成可独立交付、可验收的任务。**计划文件存在不代表功能已实现。** 修改前读本文件、[共同约定](00-contracts.md)、目标任务及其前置任务；业务背景见 ../DESIGN.md，详细规则见 ../IMPLEMENTATION.md。任务状态更新必须以代码和测试为依据。

## 当前基线

已具备真实登录、简洁账号密码表单、桌面左菜单右内容／移动抽屉、Admin 全周课表、Teacher 自己的课次／名单／学生列表、基础学生录入（姓名、年级、当前 Admin 自动负责）、OpenAPI、迁移和 seed。Teacher 首页重定向自己的课表。当前导航只显示已经实现的入口；下表的系统管理和其余业务模块为待开发目标，不放可点击的空壳管理页。

学生基础档案允许没有联系人，代表尚未完成咨询。**创建咨询和预约前**才要求可联系家长及课程偏好，不把孤立的学生行冒充完整咨询。当前 seed 的 TRIAL 名单仍不是完整预约记录。

## 目标左侧菜单

| 分组 | Admin 入口 | Teacher 入口 |
| --- | --- | --- |
| 工作台 | 概览 / 我的待办 | 不提供机构概览 |
| 教学管理 | 周课表 / 试听管理 | 我的课程（实际课次）/ 我的学生 |
| 资源管理 | 家长管理 / 学生管理 / 班级管理 / 课程管理（科目目录） | 无资源管理组 |
| 系统管理 | 账号管理 / 菜单管理 / 操作记录 | 无 |
| 课时与订单（二期） | 课时包 / 购买订单 / 课时流水 | 无 |

老师课堂反馈在课次详情里提交；沟通记录、意向分析在学生详情／待办里，不另外造一套孤立的数据入口。班级课表就是周课表按班级筛选。全局搜索、批量导入、家长端、自动排课、在线付款、营销消息发送不在首版。
